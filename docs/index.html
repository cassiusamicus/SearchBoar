SearchBoar

A combined local and network file search tool for Linux — regex filename/content search, PDF/DOCX extraction, favorites, stored searches, and SMB/NFS network search, all in one Go/Fyne binary.

Download for Linux Read the README
Features

One search engine, local and networked

🔍

No regex required

The Expr. Wizard covers "all of these words," "any of these words," and "words near each other" in plain language — Custom regex is still there if you want it, but you never have to.

📄

PDF & DOCX built in

Content extraction for PDF/DOCX ships in the binary — no external dependency required. ripgrep and pdftotext are optional speed/quality boosts, auto-detected with an install prompt.

🌐

Local + SMB + NFS

One Workspace Builder tree covers local drives and network shares. Only the shares you check get mounted, in a single elevated batch — never a wall of prompts.

⭐

Favorites & stored searches

Categorize favorite results, save named filename/content patterns, and reuse them from a quick-select dropdown right on the Start tab.

🗃️

Result caching

Extracted text is cached by path/mtime/size, so repeat searches over unchanged files — especially PDFs and network shares — skip re-extraction entirely.

🎨

Nord theme, dark & light

A dark/light toggle and a configurable accent color, with contrast-aware text so a custom accent never becomes unreadable in either mode.

Get started

Install

Download a release

tar xf searchboar-linux-amd64.tar.gz
./searchboar

Pre-built for linux/amd64, linux/arm64, and linux/armv7 — see Releases.

Build from source

git clone https://github.com/cassiusamicus/SearchBoar.git
cd SearchBoar
go build -o searchboar ./cmd/searchboar

Requires a C toolchain (Fyne's desktop backend links GLFW/OpenGL/X11 via cgo) and the usual Linux GUI dev libraries (X11, GL, Wayland, xkbcommon).
